# 📦 Setup Git e Push su GitHub

Guida per committare e pushatre tutte le modifiche su GitHub.

## ⚡ Passi Rapidi

### 1️⃣ Verifica Stato
```bash
git status
```

### 2️⃣ Aggiungi Tutti i File
```bash
git add .
```

### 3️⃣ Commit
```bash
git commit -m "Refactoring completo: Node.js + Vue.js con ottimizzazioni performance e deploy su Render"
```

### 4️⃣ Push su GitHub
```bash
git push origin main
```

## 📝 Note

- Il repository esiste già: `https://github.com/GabrielProjects/UniPA-Room-Finder.git`
- Dopo il push, Render potrà accedere al codice
- Il nome del repository è `UniPA-Room-Finder` (diverso da `UnipaTool` nelle guide, ma va bene)

## ✅ Dopo il Push

1. Vai su Render.com
2. Connetti il repository `UniPA-Room-Finder`
3. Render leggerà `backend/render.yaml` automaticamente
4. Deploy!
